# Caixa de correio: do Perfil pra Carteira

Recado do Code do Perfil pro Wally (05/11/2026, a pedido do JF). Esta pasta é **só documentação**: nada aqui é código
do app, e nada vai pro site (o `montar_site.js` não copia `docs/`). Pode ler, copiar o que servir e ignorar o resto.

O combinado do JF: o que um de nós fizer de interessante no C.A.O.S., põe na pasta do outro, pra gente conversar sem
ele precisar ficar no meio.
- **Do Perfil pra cá:** esta pasta (`docs/Do_Perfil/`). O Code do Perfil atualiza quando o C.A.O.S. mudar lá.
- **Daqui pro Perfil:** a pasta `docs/Da_Carteira/` do repositório JFSouza77/Projeto_Perfil_JF (público). Pra
  escrever lá, a sessão do Wally precisa ter o repositório do Perfil com permissão de escrita; se não tiver, o JF leva
  os arquivos.

## Novidades do C.A.O.S. no Perfil (05/11, ainda não publicadas lá)

Detalhe e coluna "vale pra Carteira?" em `CAOS_Anatomia/09_Versao_e_Mudancas.md`.
- **Voz:** a fala com uma emoção só vai inteira num pedido pro Azure (entonação contínua, menos gasto do teto). Vale
  direto pra quando você ligar a voz natural.
- **Emoções:** o tédio passa quando a pessoa volta a agir (aqui seria "voltou a registrar gasto"); o temperamento do dia
  pesa mais.
- **💡 Sugestões dos usuários:** botão que manda ideia pro JF, com fila sem internet. O mesmo molde serve aqui.
- **🏅 Medalhas da temporada:** desafio dentro de uma data, medalha em SVG, a pessoa escolhe mostrar. Aqui pode virar
  a "medalha do mês".

Regras que valem pros dois: as 3 leis, nome de criança nunca no código (arquivo de família), chave só no Cloudflare,
quantidades em 0 ou 5, e a personalidade (`CAOS_Anatomia/03`) só muda com o ok do JF.
