# Rascunho das Novidades

Ideia do Code do Perfil (16/11/2026). Aqui vai sendo anotado o que muda no app **antes** de virar versão. Quando a lista
fecha (até 7 itens, ou o assunto muda), a entrada vai pro `js/novidades.js` já no jeito certo: "emoji Título: o que é,
onde fica e como usa".

Leva de ajustes miúdos pode entrar na versão aberta com o campo `ate` (`{ v: '2.1.1 Alfa', ate: '2.1.1.2' }`): o app
mostra "2.1.1.2 Alfa" e a tela de Novidades mostra "Versão 2.1.1 Alfa · até a 2.1.1.2".
